# Client Workflow Map

## Current process

1. Customer submits a request.
2. Support agent receives the request.
3. Agent searches available policy documents.
4. Agent identifies the relevant policy.
5. Agent prepares a response.
6. Agent responds to the customer.
7. Customer issue is closed or escalated.
